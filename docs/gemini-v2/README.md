# How to run these with Gemini

- 27 files, 50 schools each, ordered biggest and most-searched first. Files 23–27 are a second try at larger schools Gemini came back empty on last time.
- Use Gemini with Google Search (Deep Research or a model with search turned on).
- One file per new chat: paste the whole file as your message.
- If it stops partway, reply "continue". When it's done, copy the full reply into a .txt file named after the file (for example file-01.txt) and send it to Claude.
- Quick sanity check before sending: every line should start with {"slug": and the dates should be today's date.
