State Profile - Vermont

July 2022

TRANSFER AND ARTICULATION 2022
Statewide common course numbering
No
Description of statewide common course numbering
Does not have statewide common course numbering; however, the Vermont State College System maintains a single-course database, which includes a single-course number, title, and single sentence description.
Source
VSC Policy 111
Transferable core of lower- division courses
No
Description of transferable core of lower-division courses
Does not have transferable core lower-division courses.
Statewide guaranteed transfer of an associate degree
No
Description of statewide guaranteed transfer of an associate degree
Does not have statewide guaranteed transfer of an associate degree; however, the state has a special transfer agreement between the Community College of Vermont and the Vermont State Colleges that allows CCV graduates to receive junior status at any Vermont State College.
Statewide reverse transfer
No
Description of statewide reverse transfer
Reverse transfer is done at individual institutions.
